# Домашняя страница

Первая учебная работа Севрюкова Ярослава Сергеевича, группа 251-361, по курсу «Основы веб-технологий».

Открыть `index.html` в браузере. Страница сделана с использованием HTML и CSS, шрифт Roboto подключён через Google Fonts.

Для публикации: загрузить содержимое папки в GitHub-репозиторий и включить Settings → Pages → Deploy from a branch → main / (root).
